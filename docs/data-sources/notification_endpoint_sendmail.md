# Data Source: proxmox_notification_endpoint_sendmail

Reads a Proxmox VE sendmail notification endpoint by name. Requires `Mapping.Audit` or `Mapping.Modify` on `/mapping/notifications`.

## Example Usage

```terraform
data "proxmox_notification_endpoint_sendmail" "ops" {
  name = "ops-sendmail"
}

output "ops_recipients" {
  value = data.proxmox_notification_endpoint_sendmail.ops.mailto
}
```
