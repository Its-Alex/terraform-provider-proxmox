# Data Source: proxmox_notification_matcher

Reads a Proxmox VE notification matcher by name. Requires `Mapping.Audit` or `Mapping.Modify` on `/mapping/notifications`.

## Example Usage

```terraform
data "proxmox_notification_matcher" "backup_failures" {
  name = "backup-failures"
}

output "backup_failure_targets" {
  value = data.proxmox_notification_matcher.backup_failures.target
}
```
