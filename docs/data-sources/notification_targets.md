# Data Source: proxmox_notification_targets

Returns the aggregate list of all configured notification targets across every endpoint type (sendmail, smtp, gotify, webhook). Read-only. Requires `Mapping.Audit`, `Mapping.Modify`, or `Mapping.Use` on `/mapping/notifications`.

## Example Usage

```terraform
data "proxmox_notification_targets" "all" {}

output "all_target_names" {
  value = [for t in data.proxmox_notification_targets.all.targets : t.name]
}

output "user_created_sendmail_targets" {
  value = [
    for t in data.proxmox_notification_targets.all.targets :
    t.name if t.type == "sendmail" && t.origin == "user-created"
  ]
}
```
