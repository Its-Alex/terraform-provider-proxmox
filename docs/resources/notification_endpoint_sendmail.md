# Resource: proxmox_notification_endpoint_sendmail

Manages a Proxmox VE sendmail notification endpoint (`/cluster/notifications/endpoints/sendmail`). Requires `Mapping.Modify` on `/mapping/notifications`; create/update additionally require one of `Sys.Audit`, `Sys.Modify`, or `Sys.AccessNetwork` on `/`. Available since PVE 8.1.

## Example Usage

```terraform
resource "proxmox_notification_endpoint_sendmail" "ops" {
  name         = "ops-sendmail"
  mailto       = ["ops@example.com", "oncall@example.com"]
  mailto_user  = ["root@pam"]
  from_address = "alerts@example.com"
  author       = "Proxmox VE"
  comment      = "Primary on-call alerting"
}
```

### Required

### Optional

- `disable` (Boolean) Whether the endpoint is disabled. Defaults to `false`.
